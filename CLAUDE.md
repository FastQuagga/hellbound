# HELLBOUND — клон DOOM

Однуровневый клон DOOM на чистом JS (ES-модули, Canvas 2D рейкастер, WebAudio).
Без зависимостей и без бинарных ассетов — всё генерируется процедурно.

## Правила проекта
- Контракт архитектуры: `docs/architecture.md` — имена экспортов и ключи ассетов
  менять только синхронно во всех модулях.
- Запуск: `python3 -m http.server 8777` из корня, открыть `http://localhost:8777`.
- Проверка синтаксиса: `node --check <файл>` (package.json задаёт type=module).
- Внутреннее разрешение 480×300, целевые 60 FPS — в кадровом цикле без аллокаций.
- Стиль ассетов: пиксель-арт по сетке, без плавных градиентов (см. §4 architecture.md).
