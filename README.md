# HELLBOUND

Полноценный клон **DOOM (1993)** на чистом JavaScript: Canvas 2D рейкастер,
WebAudio-синтез звука и музыки, все ассеты генерируются процедурно — ни одного
бинарного файла и ни одной зависимости.

## Запуск

```bash
cd fable-test
python3 -m http.server 8777
# открыть http://localhost:8777
```

(подойдёт любой статический сервер; открытие `index.html` напрямую не сработает —
нужны ES-модули)

## Что внутри

- **Уровень**: ТЕХБАЗА «ГЕФЕСТ-1» — техбаза → открытый двор → кислотный резервуар →
  адская зона; синий/жёлтый/красный ключи, 3 тайника, рубильник выхода.
- **Оружие (7)**: кулак, пистолет, дробовик, пулемёт, ракетница, плазмаган, BFG-9000.
- **Враги (6)**: зомби, сержант, имп, демон, какодемон, барон ада. ИИ: пробуждение
  по виду/шуму, преследование, боль, infighting, дропы.
- **Механики**: ключ-карты, двери, секретные стены, взрывающиеся бочки, кислотный
  пол, автокарта (Tab), статистика уровня, 4 сложности, melt-переходы экрана.
- **Меню**: титул, выбор сложности, настройки (звук/музыка/мышь), управление,
  пауза, экран статистики, финальный текст.
- **HUD**: лицо героя, реагирующее на здоровье/урон/подборы; патроны, броня, ключи.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / ↑↓ | движение |
| ←→ / мышь | поворот |
| Shift | бег |
| Ctrl / ЛКМ | огонь |
| E / Space | открыть дверь, нажать рубильник |
| 1–7 / колесо | выбор оружия |
| Tab | автокарта |
| Esc | пауза |

Отладка: `http://localhost:8777/?debug` — счётчик FPS.
