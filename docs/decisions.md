# Журнал решений

## 2026-06-09 — Технологический стек
**Решение:** чистый JS + Canvas 2D рейкастер (Wolfenstein-сетка с дверями, небом,
анимированными текстурами), WebAudio-синтез звука/музыки, ассеты процедурные.
**Почему:** нулевые зависимости (правило: не ставить пакеты), мгновенный запуск
статическим сервером, полный контроль над «дум-овским» видом; растровый рейкастер
даёт аутентичную картинку 1993 года при простом коде.

## 2026-06-09 — Мульти-агентная сборка по жёсткому контракту
**Решение:** docs/architecture.md фиксирует все API и ключи ассетов; 18 агентов
пишут модули параллельно, интегратор пишет map.js/game.js/main.js и сшивает.
**Почему:** игра слишком велика для одного прохода; контракт устраняет рассинхрон.

## 2026-06-09 — Геймплейные упрощения относительно DOOM
- Высота стен фиксированная (1 клетка), перепадов пола нет — компенсируется
  светозонами, небом, кислотой и плотным левел-дизайном.
- Спрайты врагов только анфас (без 8 ротаций) — стандарт для клонов.
- Вертикальный взгляд — y-shear (как в Heretic), прицел по вертикали через pitch.
- Секреты — потайные двери (выглядят стеной), а не push-walls.
